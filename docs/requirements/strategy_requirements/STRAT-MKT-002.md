# STRAT-MKT-002 — Languages Where the Books Sold

**Status:** ❌ Pending (written 2026-11-24)

> Version 2. The language order is the agent's proposal from the research, not an owner decision.

## Intent
The book wave was strongest in those markets, and a competitor already shows what half-translated text looks like.

## Requirement
After the English launch, the first added languages are Spanish, Dutch and German, each shipped only when all of its clue templates and UI text are complete and reviewed.
