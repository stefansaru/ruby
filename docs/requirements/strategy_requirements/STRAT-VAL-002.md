# STRAT-VAL-002 — Respect: No Gates, No Nags

**Status:** ❌ Pending (written 2026-11-24)

## Intent
Daily keys and a rating prompt 'after every puzzle, including the first' are quoted complaints about two of the larger competitors.

## Requirement
The game never stops a player from playing to make them wait, pay or watch, and never asks for a rating before they have solved a set number of cases.

## Strategic Sources
- [VisionMissionValues.md](../../strategy/VisionMissionValues.md)
- [PainPointsAndConcepts.md](../../strategy/PainPointsAndConcepts.md)

## Acceptance Criteria
- [ ] No timer, energy, key or daily limit exists
- [ ] Cases unlock only by solving earlier cases, with the rule shown to the player
- [ ] The rating prompt obeys APP-UX-006
