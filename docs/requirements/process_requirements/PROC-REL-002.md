# PROC-REL-002 — The Listing Says Only What Is True

**Tags:** Process, Release, Marketing, Honesty
**Status:** ❌ Pending (written 2026-11-24)

## Requirement
Every claim in the store listing, screenshots and campaign is true of the build being released. Draft copy tags each claim with the feature it needs, and untrue claims are removed before upload. Counts are taken from the build. Languages named are complete. The word 'Murdoku', competitors' names and claims about how the art was made are not used.

## Why
The product's position is honesty and fairness; a listing that overstates is the first unfair clue. Store policy also forbids misleading claims.

## Acceptance Criteria
- [ ] Each listing sentence maps to a shipped feature at release review
- [ ] Screenshots are from the release build
