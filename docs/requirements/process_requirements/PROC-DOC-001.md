# PROC-DOC-001 — Rules Carry Their Reason and Date

**Tags:** Process, Documentation
**Status:** ⚠️ Partial (written 2026-11-24)

> Partial: a convention, not checked by a tool.

## Requirement
Every rule in the docs states why it exists and when it was decided. The docs describe the present; text that stopped being true moves to History.md. Work not done is in TODO.md, work done is in DoneLog.md.

## Why
A rule without its reason gets broken by the next person who finds it inconvenient, and re-decided by the one after.

## Acceptance Criteria
- [ ] New rules in a commit have a reason and a date
- [ ] No doc describes a removed behaviour as current

## Implementation
Followed in the docs written on 2026-11-24.
