# APP-GAM-008 — Tutorial

**Tags:** Gameplay, Onboarding
**Status:** ❌ Pending (written 2026-11-24)
**NORM Sources:** (derived; no normative register exists yet)

## Requirement
The first cases are a guided tutorial on a small grid that teaches, one idea at a time: one person per row and column, objects you can and cannot stand on, reading a clue, 'beside', the victim in the last square, and naming the murderer. Later rules are introduced by a short card the first time a case uses them.

## Why
A newcomer has five minutes and will not read a rules page. Competitors that introduce one clue type at a time are praised for it.

## Acceptance Criteria
- [ ] A player can finish the first case without leaving the case screen
- [ ] Each new rule or clue type has an introduction shown once and available again from the glossary
- [ ] The tutorial can be skipped and replayed
