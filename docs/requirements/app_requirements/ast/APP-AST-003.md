# APP-AST-003 — Portraits Are Cosmetic Unless a Clue Says Otherwise

**Tags:** Assets, Art, Rules
**Status:** ❌ Pending (written 2026-11-24)
**NORM Sources:** (derived; no normative register exists yet)

## Requirement
A person's picture carries no information for the puzzle unless a trait is part of the case's data and a clue names it. A trait that clues can use is always shown as text or an icon on the person's card, not only in the picture.

## Why
The source books state the same rule in their FAQ. A trait visible only in a small pixel portrait would be an ambiguity of exactly the kind the game exists to remove.

## Acceptance Criteria
- [ ] Traits used by clues appear in the cast data and on the card
- [ ] No case can be solved faster by studying the art
