# APP-AST-002 — Objects Read at a Glance

**Tags:** Assets, Art, Clarity
**Status:** ❌ Pending (written 2026-11-24)
**NORM Sources:** (derived; no normative register exists yet)

## Requirement
Each object is recognisable at the smallest square the game draws, and the player can tell without tapping whether it can be stood on or blocks. Objects that clues distinguish look clearly different.

## Why
Realistic art that 'can make it hard to see clues' is a quoted complaint; the source books mark every new object as occupiable or not.

## Acceptance Criteria
- [ ] Each setting's object set is reviewed at the smallest square size
- [ ] Occupiable and blocking objects differ by a consistent visual cue as well as by picture
- [ ] No two objects in a setting can be confused
