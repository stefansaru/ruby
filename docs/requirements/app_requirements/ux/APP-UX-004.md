# APP-UX-004 — Glossary and Object Guide in the Game

**Tags:** UX, Clarity, Help
**Status:** ❌ Pending (written 2026-11-24)
**NORM Sources:** (derived; no normative register exists yet)

## Requirement
From any case the player can open a glossary of the words clues use (beside, alone, with, alone with, corner, border, and the rest), each with a small picture, and a guide to the case's objects showing which can be stood on and which block.

## Why
The book the genre comes from needs a glossary page and an objects page; an app can put them one tap away. The market leader added an object catalogue after launch.

## Acceptance Criteria
- [ ] Every term used by a clue template has a glossary entry
- [ ] Every object in a setting appears in the guide with its kind
- [ ] The glossary is reachable without leaving the case
