# APP-UX-006 — No Early Rating Prompt

**Tags:** UX, PlayerRespect
**Status:** ❌ Pending (written 2026-11-24)
**NORM Sources:** (derived; no normative register exists yet)

## Requirement
The in-app review prompt is not shown before the player has solved a set number of cases, never during a case, never twice in a row, and never again after the player declines twice.

## Why
'Asks you to rate after every puzzle. Including the first.' is a quoted complaint about the market leader.

## Acceptance Criteria
- [ ] The threshold is a named constant
- [ ] The prompt only appears on the solved screen
- [ ] Declining is remembered
