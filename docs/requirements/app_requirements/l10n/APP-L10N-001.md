# APP-L10N-001 — All Player Text from Templates

**Tags:** Localisation, Engine, Content
**Status:** ⚠️ Partial (2026-11-24)
**NORM Sources:** (derived; no normative register exists yet)

## Requirement
The engine never returns finished English sentences as data. A clue, a hint step and a story line are structured values that a wording layer turns into text for the current language, with names, areas, objects and grammatical gender supplied as parameters.

## Why
It makes a clue's wording identical everywhere it appears, and makes a new language translation work, not engineering.

## Acceptance Criteria
- [x] Generated packs store clues in typed notation, not sentences
- [x] Changing a template changes every case's text with no regeneration
- [ ] Names of people, areas and objects are looked up per language

## Implementation
Engine side built (2026-11-24): packs store clues in typed notation and the sentence is made when asked for by `describeClue`, so a template change needs no regeneration. Open: English is the only wording layer and it is code, not a template file; names of people, areas and objects are stored in English in the case text; hint steps have no wording and story lines do not exist.
