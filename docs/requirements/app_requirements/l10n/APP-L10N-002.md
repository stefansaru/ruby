# APP-L10N-002 — English First, A Language Only When Complete

**Tags:** Localisation, Release
**Status:** ❌ Pending (written 2026-11-24)

## Requirement
Version 1 ships in English. Another language is offered only when every template, name and UI string in it is complete and reviewed by a fluent reader. No screen mixes two languages.

## Why
A competitor shows Spanish strings in its English screenshots.

## Acceptance Criteria
- [ ] A test fails when any key is missing in an offered language
- [ ] The listing names only complete languages
