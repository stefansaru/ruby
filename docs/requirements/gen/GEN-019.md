# GEN-019 — No statement can be left out

**Status:** enforced
**Since:** 2026-11-24

## Requirement

In a shipped case, removing any one clue leaves more than one solution, except that a suspect's only statement always stays.

This is about the clues. Extra statements (GEN-035, 2026-11-25) are help the player asks for and are by definition not needed.

## Why

A clue that changes nothing is noise the player still has to read and check.

## How it is enforced

The drop pass at the end of `chooseClues`; `checkShipped` retries the removal of every clue on every stored case.
