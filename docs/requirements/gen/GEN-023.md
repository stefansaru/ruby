# GEN-023 — The engine decides, the view draws

**Status:** enforced
**Since:** 2026-11-24

## Requirement

lib/engine/ is pure Dart: no Flutter, no dart:io, no generator, no data. lib/gen/ has no Flutter and no dart:io. One file of the app imports it, lib/services/random_case.dart, which makes a case on request (GEN-037); screens and widgets never do. (Until 2026-11-25 nothing in the app imported the generator.)

Since 2026-11-25 the test lists what each layer **may** import instead of what it may
not: the engine only its own files; the generator `dart:math`, the engine, the data and
its own files; tools `dart:io` and the package. Services never import a screen or a
widget, widgets never a screen or a service, and screens and widgets never name
`generateCase`, `randomConfig`, `GenConfig` or `checkShipped`. *Why:* a list of
forbidden imports had holes (a generator file without the `gen_` prefix, a re-export
from the one service, `dart:html`).

## Why

The rules must be testable without a device and reusable by tools; the generator stays a plain library that a screen cannot reach into.

## How it is enforced

test/architecture_test.dart reads the import lines of every source file.

## Covered by

- `test/architecture_test.dart`
