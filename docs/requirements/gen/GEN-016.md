# GEN-016 — The same config gives the same case

**Status:** enforced
**Since:** 2026-11-24

## Requirement

Everything random in the generator comes from one `Random` seeded by the slot. The same `GenConfig` always produces the same case.

## Why

The packs must be rebuildable byte for byte, or a regenerated pack could silently change a case players have already solved.

## How it is enforced

`generateCase` creates the only `Random`; lib/gen/ has no other source of randomness and no clock.
