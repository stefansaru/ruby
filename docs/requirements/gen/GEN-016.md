# GEN-016 — The same config gives the same case

**Status:** enforced
**Since:** 2026-11-24

## Requirement

Everything random in the generator comes from one `Random` seeded by the slot. The same `GenConfig` always produces the same case.

`test/architecture_test.dart` also fails if a file of the engine or the generator
names `DateTime`, `Stopwatch` or an unseeded `Random()` (2026-11-25).

## Why

The packs must be rebuildable byte for byte, or a regenerated pack could silently change a case players have already solved.

## How it is enforced

`generateCase` creates the `Random` a case is drawn from; `randomConfig` in lib/gen/gen_campaign.dart makes a second one from the same seed to pick the shape, setting and title of a case made on request (2026-11-25). lib/gen/ has no other source of randomness and no clock.

## Covered by

- `test/gen/gen_test.dart`
- `test/architecture_test.dart`
