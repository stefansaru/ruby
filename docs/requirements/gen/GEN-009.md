# GEN-009 — Writing a parsed case gives the same text back

**Status:** enforced
**Since:** 2026-11-24

## Requirement

`writeCase(parseCase(text))` equals `text` for any text `writeCase` produced, and every shipped case is stored exactly as `writeCase` writes it.

## Why

The packs are text. If reading and writing disagreed, the case the solver certified would not be the case that ships.

## How it is enforced

The well-formed gate in `generateCase`; the data tests compare each stored case with its rewritten form.

## Covered by

- `test/engine/case_text_test.dart`
- `test/data/packs_test.dart`
