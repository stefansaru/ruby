# GEN-018 — Gates run in a fixed order and are counted

**Status:** enforced
**Since:** 2026-11-24

## Requirement

A draw passes the gates scene, unique, wellFormed, logic, tier, variety in that order. The funnel counts how many draws passed each gate; a slot that runs out of attempts returns no case.

## Why

When a slot is hard to fill, the funnel shows which gate is the narrow one. Without it tuning the generator is guesswork.

## How it is enforced

`generateCase` and the `Gate` enum in lib/gen/gen_case.dart; `tool/generate_cases.dart` prints the funnel per tier.
