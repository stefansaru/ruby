# GEN-013 — The logic solver is never wrong

**Status:** enforced
**Since:** 2026-11-24

## Requirement

The logic solver never rules out the true square. When it reports solved, its placement obeys every rule and clue; on every shipped case it equals the certified solution. A case with two answers is never reported solved.

## Why

Hints come from this solver. A hint that points at a wrong square is worse than no hint.

## How it is enforced

`_Solver._obeys` verifies the final placement; `checkShipped` compares it with the certified solution on every case.
