# GEN-007 — A stated solution must solve the case

**Status:** enforced
**Since:** 2026-11-24

## Requirement

When a case carries a `solution` line, the case parses only if that placement obeys every rule and clue.

## Why

The certified solution is what the game compares the player's answer with; a wrong one would mark correct play as wrong.

## How it is enforced

`parseCase` runs `CaseDef.check` on the stated solution.

## Covered by

- `test/engine/case_text_test.dart`
- `test/engine/hardening_test.dart`
