# GEN-031 — The victim is placed last

**Status:** enforced
**Since:** 2026-11-24

## Requirement

The logic solver never places the victim while a suspect is still unplaced, unless the player has already put the victim down. A case ships only when it is solved this way, and a hint never names the victim before every suspect is placed.

## Why

Nothing is said about the victim, so a person solving finds the victim at the end, on the square that is left. A solving path (and a hint) that said "the victim can be placed now" after two suspects could not be followed (owner report, 2026-11-24, `input/problem2`).

## How it is enforced

`_victimWaits` in lib/engine/logic_solver.dart, used by the single and intersection techniques; `checkShipped` checks the last placement of the solving path; `CaseSession.hint` takes its order from the solver.
