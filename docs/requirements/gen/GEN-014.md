# GEN-014 — Every shipped case is solved without guessing

**Status:** enforced
**Since:** 2026-11-24

## Requirement

The logic solver, using only its named techniques, places everyone in every shipped case.

## Why

"Do I ever have to guess? No." is a promise of the genre. A case the solver cannot finish may need a guess, so it does not ship.

## How it is enforced

The logic gate in `generateCase`; `checkShipped`.

- `test/engine/solver_test.dart`
