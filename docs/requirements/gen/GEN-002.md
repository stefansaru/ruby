# GEN-002 — A person stands on floor or on an object that can hold one

**Status:** enforced
**Since:** 2026-11-24

## Requirement

A square holding a blocking object (table, tree) never holds a person. Bare floor and objects marked `sit` (chair, bed, boat) do.

## Why

Players read the scene to see where people can be; a person on a table would make the picture lie.

## How it is enforced

`CaseDef.canOccupy`; the parser refuses an `on` clue naming a blocking kind; the solvers start from occupiable squares only.
