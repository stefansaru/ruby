# GEN-029 — Every object stands in an area it belongs in

**Status:** enforced
**Since:** 2026-11-24

## Requirement

Each area of a setting lists the objects that belong in it (`AreaSpec.kinds` in `lib/data/settings.dart`). The generator places an object only in an area that lists it, every object is listed by at least one area, and a shipped case with an object in an area that does not list it is refused.

An object that blocks a square must be a real obstacle there: the Train has a suitcase where it had a lamp (2026-11-25); a lamp blocks only where it is a lamp post.

## Why

The first playable build put boats in the Pines, the Clearing and on the Path, because the old rule only knew "inside" and "outside" (owner report, 2026-11-24, `input/problem1`). A scene that makes no sense makes the clues about it feel arbitrary.

## How it is enforced

`drawScene` in lib/gen/gen_scene.dart draws from `setting.kinds.where(spec.allows)`; `misplacedObject` in lib/gen/gen_check.dart, called by `checkShipped`, checks every square of a stored case against the list.
