# GEN-022 — Packs are generated source and can be rebuilt exactly

**Status:** enforced
**Since:** 2026-11-24

## Requirement

Each pack is a Dart file written by `tool/generate_cases.dart`, starting with a GENERATED header. Running the tool again reproduces every pack byte for byte.

## Why

Packs are code so a broken case fails to compile or fails a test. Exact rebuilds prove the committed packs are what the committed generator makes.

## How it is enforced

`renderPack`; `dart run tool/generate_cases.dart --dry-run` compares with the files on disk and exits 1 on any difference.

## Covered by

- `test/data/packs_test.dart`
- `test/architecture_test.dart`
