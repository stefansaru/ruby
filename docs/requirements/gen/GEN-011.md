# GEN-011 — One liar means exactly one false statement

**Status:** enforced
**Since:** 2026-11-24

## Requirement

In a liar case exactly one statement made by a suspect is false. General clues and case rules are always true. A liar case has at least two statements.

## Why

The rule has to be exact for the case to be solvable: the player tests each statement as the lie.

## How it is enforced

`CaseDef.check` counts broken statements; `solveExact` and `solveLogic` try each statement as the lie; the parser refuses a liar case with fewer than two statements.
