# GEN-027 — Grids need not be square

**Status:** enforced
**Since:** 2026-11-24

## Requirement

Each grid holds as many people as its shorter side. On a grid with more rows than columns the extra rows stay empty (and likewise columns), and the game says so as a rule sentence.

## Why

Non-square scenes (a train, a ship) are part of the genre; stating the empty lines removes a guess.

## How it is enforced

`GenConfig.people`; `describeRules`; the logic solver's full-line rule in `_findFullLines`.
