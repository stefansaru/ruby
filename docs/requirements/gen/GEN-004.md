# GEN-004 — Every clue has one meaning

**Status:** enforced
**Since:** 2026-11-24

## Requirement

A clue is one object with one `holds` function. The sentence shown to the player, the text notation and the solver pieces are all derived from that object.

## Why

The most reported fault in this genre is a clue that can be read two ways. One definition, with the wording generated from it, makes a mismatch between text and check impossible.

## How it is enforced

`Clue.holds` in lib/engine/clue.dart; `describeClue` in wording.dart and `clueNotation` in case_text.dart switch over the same sealed types, so a new clue type does not compile until all three handle it.
